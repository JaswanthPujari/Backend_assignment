# User Management API

## 🚀 Features
- CRUD operations
- Search users
- Sort users
- SQLite database

## 🛠 Tech Stack
- Node.js
- Express
- SQLite

## 📦 Installation
npm install

## ▶️ Run
npm start

## 📌 API Endpoints

GET /users  
GET /users/:id  
POST /users  
PUT /users/:id  
DELETE /users/:id
